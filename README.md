# OpenWrt x86_64 云编译

为 Intel x86_64 小主机生成 UEFI / SquashFS 固件，源码为 Lean LEDE。
**这是待云端验证的构建配置，不是已编译成功的固件。**

## 功能

- SSR Plus + Xray + Mihomo + SSR 客户端，采用 firewall4 / nftables。
- VSSR 不再强行保留；旧 VSSR 的配置不能直接当作 SSR Plus 配置恢复。
- LuCI 中文界面、网页终端、流量统计、常见 Intel/Realtek 网卡和 USB 存储支持。
- 不包含多拨、ZeroTier，也不预置节点、订阅、密码或个人路由器备份。
- 源码及插件提交固定在 `sources.env`；更新时应统一检查兼容性。

## 启动编译

将本目录内所有文件提交到仓库根目录，保留 `.github/workflows/build-openwrt.yml` 路径。
GitHub 网页上传 ZIP 不会解压，不能只上传 ZIP；Mac Finder 中可用 Command+Shift+. 显示隐藏目录。

工作流会在相关文件推送到 main 时运行，也可在 Actions → Build OpenWrt x86_64 → Run workflow 手动启动。
使用公开仓库的标准 ubuntu-24.04 运行器，不使用收费的大型运行器。
工作流只在公开仓库执行，私有仓库会跳过，避免误用私有仓库的计费额度。
首次构建可能耗时数小时，也可能因上游依赖、空间或时限失败。失败时下载 `build-diagnostics-*` 查看日志。
完成后下载 `firmware-x86_64-uefi-*`，其中包括固件、SHA256、包清单、源码版本和完整配置。
工作流不创建 Release，也不会连接或刷写家里的路由器。

## 网络与首次试机

以下网口配置依据旧系统；更换内核后接口编号仍须在实际机器核对：

| 项目 | 设置 |
| --- | --- |
| LAN 管理地址 | 192.168.10.1/24 |
| LAN 桥 | eth2、eth3、eth4、eth5；STP 开启 |
| WAN | eth0，DHCP 自动获取地址 |
| WAN6 | 与 WAN 共用端口，通过 DHCPv6 获取配置；需实测 |
| eth1 | 暂不分配，旧系统独立 WAN6 用途尚未确认 |
| 磁盘分区 | 128 MiB 启动分区 + 2048 MiB 根分区，不自动扩满 U 盘 |

首次试机应与现有家庭 LAN 隔离，用电脑直连新系统的 LAN 口，避免两个 192.168.10.1 冲突。
本构建没有设置 root 密码；在隔离网络首次进入 LuCI 后立即设置密码，再接入家庭网络。
SSR Plus 初始没有订阅或节点，需要单独导入并验证 DNS、分流和代理访问。
不应将旧系统整份备份直接覆盖到新系统；先迁移必要设置。

只计划使用已确认可清空的 64GB U 盘试机；保留当前 32GB 启动盘和内置 SSD。
当前仍未提供任何磁盘写入命令。实际写盘前须重新核对目标设备、备份和镜像校验值。

## 维护边界

这是自编译 Lean 固件，不是官方 OpenWrt 发布版。
默认不启用没有对应构建的软件包下载源，保留软件包签名校验。
需要新软件时优先重新构建或使用同一源码/内核构建的包，不随意切换官方软件源或强制安装内核模块。
以后可以从 GitHub 手动重建并下载固件；这不等于已经配置路由器内的一键自动升级。
构建通过只能证明产物生成，不能代替实机启动、网口、DNS 和代理功能验收。
